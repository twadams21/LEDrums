claim: `packages/core/src/voice/types.ts:102` and `packages/core/src/effects/types.ts:9` both export an interface named `ParamSpec` describing an effect parameter, with identical key/label/min/max/step/unit/options/default fields. The ONLY difference is the value-type discriminant: `kind: 'number'|'bool'|'enum'|'color'` versus `type: ParamType`. Rather than reconciling them, `modulation.ts:215` introduces `ModParamSpec { key: string; kind?: string; type?: string; min?; max? }` — both discriminants optional and both widened to bare `string` — with `isNumberSpec = (s) => (s.kind ?? s.type) === 'number'`.
