claim: The message handler's catch does `ws.send(encodeServer({ t: 'error', message }))` where `message` is `err.message` verbatim. For a ZodError that is a multi-line path dump of the project schema; for a filesystem fault it is an absolute path on the drummer's machine (`/Users/<name>/…`), leaked to whoever holds the room PIN over the public Cloudflare tunnel. It is also the only error surface that is NOT rate-limited: a client sending malformed messages in a loop gets an error frame per message, and each one also emits a Monitor event that feeds the #122 reporter, so a misbehaving client can amplify itself into the telemetry pipeline. The `handled` flag correctly distinguishes decode failures from handler failures, so the structure for a differentiated response already exists.
