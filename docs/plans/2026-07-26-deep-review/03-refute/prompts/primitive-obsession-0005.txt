claim: A displayed measurement is the pair (numeric value, unit). Slider throws the pair away and tries to recover the unit by string-diffing the caller's `format(value)` output against its own `formatNumber` output (Slider.svelte:44, 65-71). When neither `startsWith` nor `endsWith` matches, `inferUnit` returns the ENTIRE formatted string as the "unit" (line 70), which is then rendered in a `<span class="unit">` next to the number input (lines 160-162). This fires on a shipped call: `apps/web/src/lib/app/docks/inspectors/ContainerNodeInspector.svelte:75` passes `format={pct}` where `pct = (v) => `${Math.round(v*100)}%`` (node-options.ts:116) with `min=0 max=1 step=0.01`. At value 0.5 the input shows "0.5" and the unit span shows "50%" — the control renders "0.5 50%". Same for ContainerNodeInspector.svelte:92/113/140, ModulationParamsSection.svelte:110 and EnvelopeEditor.svelte:67, i.e. every percentage slider in the app. The clean source of truth already exists one layer up: `ParamSpec.unit?: string`.

evidence the author gave:
  [read]  :: apps/web/src/lib/ui/Slider.svelte:40-44 — `inputValue = formatNumber(normalizedValue, precision)`, `display = format ? format(normalizedValue) : inputValue`, `unit = inferUnit(display, inputValue)`; lines 65-71 show the four-branch string diff ending in `return formatted`.
  [read]  :: apps/web/src/lib/ui/Slider.svelte:160-162 renders `{#if unit}<span class="unit">{unit}</span>{/if}` alongside the numeric input, so the fallback string is displayed verbatim.
  [read]  :: apps/web/src/lib/app/views/node-options.ts:116 `export const pct = (v: number): string => `${Math.round(v * 100)}%``; consumed at ContainerNodeInspector.svelte:75 with step=0.01 → inputValue '0.5', display '50%', neither prefix nor suffix match → unit = '50%'.
  [grep]  :: `grep -rn 'format={' apps/web/src/lib --include=*.svelte` lists 15 call sites; the `pct`-style ones (0..1 domain, percent display) all hit the fallback branch, as does `format={(v) => enveloped ? 'swept' : ...}` at ModifierNodeInspector.svelte:74.

proposed fix: Delete `inferUnit`. Give Slider an explicit `unit?: string` prop and let callers pass the unit they already have (`ParamSpec.unit` at PlayNodeInspector/ModifierNodeInspector; a literal '%' / 'ms' / '°' elsewhere), with `format` responsible only for the numeric text. That makes the value/unit pair a declared contract instead of something guessed from a rendered string, and removes 7 lines of heuristics from a design-system primitive. Add the `unit` prop to the styleguide entry in the same change per AGENTS.md.
